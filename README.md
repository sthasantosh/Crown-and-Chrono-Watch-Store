# Crown & Chrono Watch Store

A multi-page watch e-commerce website built using HTML, CSS, and JavaScript.

## Features

- Home page
- Product categories
- Premium, analog, smart, and vintage watch sections
- Blog page
- Research page
- About Us page
- Product details
- Form validation using JavaScript
- JavaScript pop-up messages
- Responsive layout
- User-friendly navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Figma
- Visual Studio Code

## Project Purpose

This project was developed as a front-end e-commerce website for a watch store. It focuses on webpage structure, styling, navigation, product presentation, form validation, and interactive elements.
